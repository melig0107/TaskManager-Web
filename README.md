TaskManager-Web

1. Descripción del proyecto

TaskManager-Web es una aplicación web que permite registrar y organizar tareas pendientes. Su objetivo es facilitar el seguimiento de actividades mediante una interfaz sencilla donde se pueden agregar tareas, marcarlas como completadas y eliminarlas.

3. Tecnologías utilizadas

HTML: estructura de la página.

CSS: diseño y estilos de la aplicación.

JavaScript: funcionamiento de las tareas.

Git: control de versiones.

GitHub: almacenamiento del repositorio y trabajo colaborativo.

4. Instrucciones de ejecución

Para ejecutar el proyecto:

Descargar o clonar el repositorio.

Abrir la carpeta TaskManager-Web en Visual Studio Code.

Localizar el archivo index.html.

Abrirlo en un navegador web.

También se puede utilizar la extensión Live Server de Visual Studio Code.

5. Funciones principales

Agregar nuevas tareas.

Evitar el registro de tareas vacías.

Marcar tareas como completadas.

7. Flujo de trabajo: GitHub Flow

Se utilizó GitHub Flow para organizar el trabajo colaborativo. Cada integrante trabajó en una rama independiente, realizó sus cambios y registró commits para guardar los avances.

Después, las ramas se subieron al repositorio remoto y se crearon Pull Requests para revisar los cambios antes de integrarlos a main.

También se realizó una prueba de conflicto modificando una misma línea de texto desde dos ramas diferentes. Posteriormente, se revisaron los cambios y se resolvió el conflicto integrando las aportaciones de ambas integrantes.

Se eligió este flujo porque permite trabajar de manera ordenada y revisar las modificaciones antes de agregarlas a la versión principal.
